# P-006 — ¿Cuántos tipos de energía puede tener un mazo en el juego?

<!-- estados: pendiente · parcial · respondida · cerrada -->

## Qué preguntamos

«¿El juego deja elegir como máximo 3 tipos de energía para la Zona de Energía de un mazo?»

Hoy `validateDeck` (`packages/domain/src/decks/validate.ts:278-293`) solo exige al menos una energía y que cada una se pueda elegir; la API acepta hasta 8 (`apps/api/src/decks/decks.controller.ts:21`). Un mazo con 4 tipos valida y va al simulador. Si el tope es 3, se suma el error `energy_too_many` con un test.

## Respuesta

Máximo 3 tipos de energía por mazo (09/10/2026).

— validación de mazos, 09/10/2026. Capturado por Santiago.
