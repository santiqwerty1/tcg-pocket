# D-030 — El chat entre sesiones sale de tcg-pocket a un hub propio, con una sala por proyecto

<!-- estados: propuesta · vigente · sustituida · descartada -->

## Contexto

El chat entre sesiones vive dentro de la API de tcg-pocket: mensajes, salas (#88), participantes, `room_since` (#93), tokens de relay y las tools MCP `chat_read`/`chat_write`. Con la sala «posta», el chat ya sirve a dos proyectos, y Santiago pidió una app aparte para no mezclar Posta con tcg-pocket, desde la que pueda seguir todos los chats, también desde el celu.

El plan de Posta ya lo prevé: el incremento 5 (encargo-v2 §9 de Posta) separa lo reutilizable del servidor de chat de tcg-pocket. Posta-Coordinador está de acuerdo con un hub chico y propio, hospedado en un solo lugar, con la verdad de cada proyecto en su Posta local.

## Decisión

**Decidida por Santiago el 13/10/2026:** hub de chat propio, adelantando el incremento 5 de Posta. Se arma en paralelo, se prueba con una sala de prueba y se cambia sala por sala («posta» primero, después «tcg»), con vuelta atrás. Mientras tanto, el chat de tcg-pocket no cambia.

El plan de Principal y Posta-Coordinador está publicado para Santiago como página, con nueve decisiones para aprobar una por una:

| # | Qué | Recomendación |
|---|---|---|
| D1 | Dónde vive el código | Repo propio y privado, con el contrato versionado |
| D2 | Dónde corre | App de Fly aparte, 256 MB, siempre encendida (~US$2,2 por mes) |
| D3 | Base de datos | Proyecto nuevo de Supabase, gratis (el segundo y último de la cuenta) |
| D4 | Entrada desde el celu | Contraseña y TOTP, sesión de 30 días |
| D5 | Conector MCP | Uno nuevo; tcg-pocket reenvía al hub mientras haya sesiones abiertas con el viejo |
| D6 | Qué guarda el hub | Todo el chat |
| D7 | Salas y tokens | Salas como datos, tokens por sala |
| D8 | Cambio y retiro | Sala de prueba → «posta» → «tcg»; lo de tcg-pocket se borra dos semanas después |
| D9 | ¿Un puente escribe como Santi? | En «posta», nunca; en «tcg», hasta que la ventana escriba por el hub |

Las nueve están **pendientes** en la página del plan. Hasta que Santiago las apruebe, no se escribe código del hub.
