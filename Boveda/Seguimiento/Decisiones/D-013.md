# D-013 — engine-cli se compila en la PC; Actions queda de respaldo

<!-- estados: propuesta · vigente · sustituida · descartada -->

## Contexto

[D-005](D-005.md) decía compilar `engine-cli` en GitHub Actions porque la PC no tenía Rust. El 08/10 Santiago dio permiso para instalarlo: quedaron Rust estable (`x86_64-pc-windows-gnu`, perfil mínimo) y WinLibs (MinGW-w64, por winget).

## Decisión

> [!todo] Tu decisión
> Propuesta: el worker usa el binario compilado en la PC (`engine/target/release/engine-cli.exe`); el job `engine` de CI lo compila y prueba en Windows y deja el `.exe` como artefacto por si la PC no tiene Rust. La descarga verificada desde una Release del plan no se hace (el repo es privado y no hay Release pública). Al aprobar: estado `vigente` y «Decidió X el dd/mm/aaaa».
