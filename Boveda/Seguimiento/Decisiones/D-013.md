# D-013 — engine-cli se compila en la PC; Actions queda de respaldo

<!-- estados: propuesta · vigente · sustituida · descartada -->

## Contexto

[D-005](D-005.md) decía compilar `engine-cli` en GitHub Actions porque la PC no tenía Rust. El 08/10 Santiago dio permiso para instalarlo: quedaron Rust estable (`x86_64-pc-windows-gnu`, perfil mínimo) y WinLibs (MinGW-w64, por winget).

## Decisión

Decidió Santiago el 08/10/2026, con la recomendación de Claude: el motor se compila en la PC (sin token; solo se recompila cuando cambia la versión de deckgym) y CI lo compila igual como respaldo. Para saber cuándo hay una versión nueva de deckgym, la app lo revisa a diario ([T-010](../Tareas/T-010.md)).

## Aplicación

Implementado el 08/10/2026. Sigue vigente lo de [D-005](D-005.md): deckgym @ `fb792ebf` sin modificar, obra derivada AGPL no distribuida.
