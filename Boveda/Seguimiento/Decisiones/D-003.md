# D-003 — Modelo de datos: carta funcional, versión y copias

<!-- estados: propuesta · vigente · sustituida · descartada -->

## Contexto

El tracker tiene tres niveles que hay que distinguir bien: el número de carta (`card_id`), la versión (`internal_id`, el arte) y la carta funcional (`alternate_versions`, mismo nombre y texto). Santiago pidió el 07/10/2026 que la app discierna correctamente entre versiones distintas de una misma carta.

## Decisión

Decidió Santiago el 06/10/2026 (bloque A): identidad por `card_id`; carta funcional = `alternate_versions`; unidad de stock = ediciones que comparten `internal_id`; ajuste manual = valor absoluto por carta funcional.

## Aplicación

- Mazos: cualquier versión de la carta funcional sirve (copias jugables por grupo; «mejor versión» para armarlo en el juego).
- Colección: cuenta cada versión. Dos números con el mismo `internal_id` comparten copias (A1-1 = A4b-1, B1a-1 = B4b-1); un arte u holo nuevo es otra versión (B4b-237, Bulbasaur holo).
- Verificado con datos reales: [S-001](../Supuestos/S-001.md). Tests en `packages/domain/test/packs/recommend.test.ts` («versions of the same card»).
