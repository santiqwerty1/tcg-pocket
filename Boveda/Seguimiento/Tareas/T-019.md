# T-019 — Página de análisis de todas las simulaciones

## Qué

Más → Simulación → Análisis: resumen, rankings por bot, acuerdo entre bots y diferencias,
mapa de calor, empezar primero, duración, empates, ciclos y hallazgos generados desde los datos.
Reutilizar Wilson, ranking y calibración #29; fuentes separadas, n e intervalos visibles,
orientativo con n < 30. API de lectura y tool `simulations_analysis`.
