# T-009 — Probar la Fase 7 desde el celu y desde Claude Code

<!-- estados: pendiente · preparado · en_curso · bloqueado · parcial · hecho -->

## Qué

1. Más → Tokens de API: el token del conector tiene que decir `mcp:read, mcp:write`. Si dice solo `mcp:read`, crear uno nuevo con los dos y cambiar el encabezado `Authorization` del conector (claude.ai → Conectores) y de Claude Code.
2. En la app de Claude, reconectar o refrescar el conector para que liste las tools nuevas.
3. Las tres frases de aceptación: «registrá una victoria con el mazo 7 contra Mega-Blaziken, empecé yo» (desde el celu); crear un mazo desde un texto en español y recibir la validación (Claude Code); encolar una simulación con una semilla elegida.

## Hecho cuando

- [x] La partida aparece en la app («desde Claude»), el mazo nuevo valida y la simulación sale en Más → Simulación con la semilla pedida.

## Notas

Verificado en tests de integración con el cliente MCP oficial (`apps/api/test/mcp-write.e2e-spec.ts`).
