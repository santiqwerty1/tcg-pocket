# T-007 — Arrancar el worker en la PC contra producción

<!-- estados: pendiente · preparado · en_curso · bloqueado · parcial · hecho -->

## Qué

Lo hace Santiago (el token no pasa por el chat):

1. En la app: Más → Tokens de API → nuevo token de tipo **worker**; copiarlo.
2. Crear `%LOCALAPPDATA%\tcg-worker\config.json` con `{"token": "tcg_wk_…", "cores": 8}` (el servidor por defecto es `https://tcg-pocket.fly.dev`).
3. `pnpm install`, `pnpm -F @tcg/worker build` y `node apps/worker/dist/main.js --check` (dice motor, núcleos y si llega al servidor).
4. `pnpm -F @tcg/worker install-task` (tarea oculta al iniciar sesión) o, para probar, `node apps/worker/dist/main.js`.

## Hecho cuando

- [x] Más → Simulación muestra el worker «en línea» y la matriz de los 40 mazos corre en producción.
