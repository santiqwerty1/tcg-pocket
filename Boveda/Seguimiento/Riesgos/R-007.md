# R-007 — La CI de Posta no se puede instalar desde este repositorio

<!-- estados: abierto · resuelto · descartado · por_revalidar -->

## Riesgo

La CI que genera el kit hace checkout de `santiqwerty1/project-workflow-lab`, que es privado: con el token por defecto de Actions fallaría en cada push. Sin CI, la bóveda solo se valida a mano.

## Mitigación

Correr `posta check` antes de cada commit que toque `Boveda/` (el hook `Stop` lo valida). Desde la Fase 21, `pnpm deploy:fly` también lo corre y solo despliega un commit con la CI de GitHub en verde (DECISIONES 24.3). Opciones en [T-005](../Tareas/T-005.md): un token de solo lectura como secreto, o publicar Posta.
