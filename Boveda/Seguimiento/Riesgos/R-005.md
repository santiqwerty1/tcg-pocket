# R-005 — flyctl ssh console no funciona desde esta PC

<!-- estados: abierto · resuelto · descartado · por_revalidar -->

## Riesgo

El túnel WireGuard se resetea; sin consola no se pueden correr tareas puntuales en producción de la forma habitual.

## Mitigación

`flyctl machine exec <id> --app tcg-pocket "<comando>"`; para scripts con comillas, `node -e eval(atob(process.argv[1])) <base64>`. Ver [Producción](../../Operacion/Produccion.md).
