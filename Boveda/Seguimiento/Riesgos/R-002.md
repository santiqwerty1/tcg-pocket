# R-002 — El conector de Claude podría exigir OAuth

<!-- estados: abierto · resuelto · descartado · por_revalidar -->

## Riesgo

El encabezado fijo del conector remoto figura como beta para un conjunto limitado de organizaciones; si lo sacan, el conector deja de andar con el token `tcg_mcp_*`.

## Mitigación

Plan B documentado: servidor OAuth con Descope (1–2 días). Ver [D-004](../Decisiones/D-004.md).
