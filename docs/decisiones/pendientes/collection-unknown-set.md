seccion: La colección del juego vía ptcgpocket.gg (T-024, 22/10/2026)
---
| **«Tracker al día» arma el archivo aunque ptcgpocket.gg traiga cartas que el catálogo todavía no tiene**: una fila con nombre de una expansión de la que el catálogo no tiene ninguna carta (como SP1, «Primeros Compañeros», antes de que el tracker la cargue; una expansión que el catálogo lista sin cartas cuenta igual) o con un número posterior al último de su expansión (una promo nueva). Esas filas quedan fuera de la comparación y del archivo, con un aviso que las nombra («ptcgpocket.gg trae SP1-1 Bulbasaur: el catálogo todavía no tiene esa expansión…»), y `complete` queda en falso. Siguen sin archivo una fila con un número que el catálogo no tiene dentro del rango de una expansión que sí tiene (otra numeración, el S-D original) y una fila sin nombre que el catálogo no tiene. Cambia, en ese punto, la regla de 63.15. | El 29/10 ptcgpocket.gg trajo SP1-1 antes que el tracker y el catálogo, y el freno dejaba 107 cartas de C1 (221 copias) sin pasar al tracker. Lo mismo pasaría con cada promo que ptcgpocket.gg cargue antes que el tracker. Una fila así no puede ser otra numeración de las cartas que el catálogo tiene: lo único que puede esconder es una carta conocida escrita con otro código, y eso lo ataja la decisión siguiente. El catálogo numera cada expansión sin huecos, así que un número que falta dentro del rango sí sería otra numeración. |
| **Una carta que el tracker tiene, sin copias en la exportación, y que se llama como una fila con copias que no se compara como ella misma no se compara**, con un aviso que la nombra («Bulbasaur (A1-227) no se compara: ptcgpocket.gg no trae copias de esa carta, pero su nombre aparece entre las cartas de ptcgpocket.gg que no se comparan…»). Valen las filas que el catálogo no ubica (de cualquier tipo) y las que traen el nombre de otra carta (63.5); el nombre se compara con `dotggNameKey`. Vale en cualquier expansión, también en una que se compara entera en 0 (63.18). Una baja sin aplicar sigue contando como baja sin aplicar (63.21), y una carta que ya queda afuera por traer otro nombre se cuenta una sola vez. | Es el camino que dejaba abierta la decisión anterior: si ptcgpocket.gg escribiera una carta conocida, o una expansión entera, con un código nuevo, y la app ya estuviera en 0 ahí porque Santi aplicó esa sincronización, el archivo la pondría en 0 en el tracker. El nombre es lo único que une la fila con la carta, y contra el export real del 22/10 coinciden los 2.137. Cierra también el mismo hueco de las filas con el nombre de otra carta, que ya no frenaban el archivo. Una carta con copias en la exportación se compara: ptcgpocket.gg lista cada carta del juego una sola vez, así que ese número es el del juego. Límite conocido: si ptcgpocket.gg cambiara a la vez el código y el nombre, no se ataja. |
